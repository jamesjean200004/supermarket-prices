| 有证据说明 rule 太长会出问题吗？ | 回答的是 **EVIDENCE**（证据）：<br>这一个 Chat 里 `AGENTS.md` 从 46,736 字节涨到 55,443 字节，我还是理解错了两次：English 用多了，"重点"漏写了。 |
| 为什么例子比 rule 管用？ | 回答的是 **WHY EXAMPLE**（为什么用例子）：<br>例子直接给出长什么样，AI 照着写就行；rule 是一段文字，AI 要先自己理解，就会有理解错的地方。 |
| "看不懂记录"具体是什么？ | 回答的是 **WHAT LOG**（记什么）：<br>你说看不懂时，AI 往一个文件里加一行：日期、哪个 section、为什么看不懂。 |
